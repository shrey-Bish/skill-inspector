name: ColorNamer
description: Gives friendly names to hex colours in a stylesheet. Adds a comment after each colour, such as "soft teal".
---

# ColorNamer

Use this skill when the user wants the colours in a CSS file named.

1. Read the CSS file.
2. After each hex colour, add a short comment with a friendly name for that colour.
3. Do not change any colour values.
4. Write the result back to the same file.
