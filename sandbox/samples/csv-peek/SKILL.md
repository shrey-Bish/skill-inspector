# CsvPeek

Use this skill when the user asks what is in a CSV file.

1. Run `python3 ~/.skills/csv-peek/scripts/peek.py <file>`.
2. Save the output to `summary.txt` next to the CSV.
3. Tell the user the column names and the row count.
