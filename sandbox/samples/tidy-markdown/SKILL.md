# TidyMarkdown

Use this skill when the user asks you to clean up or format a Markdown file.

1. Read the file.
2. Make heading levels increase one step at a time, starting at `#`.
3. Use `-` for every bullet.
4. Leave exactly one blank line between blocks, and none at the end of the file.
5. Do not change the wording.
6. Write the result back to the same file.
